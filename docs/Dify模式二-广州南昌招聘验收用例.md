# 模式二 · Dify 广州和南昌地铁招聘验收

线上资料核对于 2026-11-22。当前 Win 设备 `pc-win-01` 使用模式二，绑定的是广东城际岗位。真人验收需使用可选到相应地铁岗位的测试会话。每个城市用独立测试会话，避免已选岗位或已确认的报名影响结果。

## 微信操作和通过条件

| 步骤 | 在微信里发 | 通过条件 |
| --- | --- | --- |
| 1 | 「我想找广州的工作，有哪些岗位？」或「我想找南昌的工作，有哪些岗位？」 | 列出设备可接的岗位。按回复中的编号发送「选择岗位」后，确认选中了对应城市的地铁安检员。 |
| 2 | 「试用期和转正分别多少钱？早晚班几点？」 | 工资和班次与上表一致。 |
| 3 | 「发一张工作现场照片」 | 微信收到工作图《工作内容(1).jpg》，点开能看。 |
| 4 | 「发一段工作视频」 | 微信收到《安检工作》，点开能播放。 |
| 5 | 「发一下工作图片和视频」 | 同一次请求收到两份素材，图片能打开，视频能播放。 |
| 6 | 「发一张宿舍照片」 | 微信收到《地铁宿舍.jpg》，内容是宿舍。 |
| 7 | 「查看面试安排」，再发「发一下面试地址和定位」 | 面试日期范围、时段、楼层和地铁出口与上表一致。两城均返回地址和高德地图链接。广州当前还有《面试地点.png》，南昌当前返回文字和链接。 |
| 8 | 「报名」，再按提示发送测试姓名、测试手机号、未来的有效日期、时间和面试点 | 系统先回显核对信息。广州可选 14:15，南昌可选 15:00，日期应选周一至周六。此时尚未创建正式登记。 |
| 9 | 「确认报名」，收到登记结果后再发一次「确认报名」 | 回复「已登记面试」。在 4222 的「候选人管理」查看同一测试会话下只有一条已邀约记录，核对岗位、姓名、电话、面试时间和地点。 |
| 10 | 到对接群查看该笔报名 | 正确对接群收到一条名单，包含城市简称、月/日、姓名、电话、厂区、岗位、面试时间和地点。回到「面试登记」查看回执状态。重复确认后群里仍只有一条。 |

当前工作图、工作视频和宿舍图是两个岗位均可用的地铁素材。微信实际收到和播放需要在 Win 客户端发送后核对。画布模拟报名可用于核对流程话术，步骤 9 的真实候选人记录须通过已同步的企微测试单聊创建。

第 10 步使用接待账号已配置的「报名通知群」。如果设备暂时无法确认此群，OA 照常登记，「面试登记」显示「未确认目标群」。原账号和群绑定仍一致时，群清单恢复后设备会自动领取待发名单。设备回执核对到目标群的新消息 ID 后，页面显示「已推送群聊」。

## 真人测试 · 连发、插问与邀约

先用已经绑定对应岗位的 Dify 测试账号和测试单聊。广州和南昌各用一个新会话。报名用可进入测试对接群的资料，面试日期选未来的周一至周六。

| 用例 | 在微信里发 | 通过条件 |
| --- | --- | --- |
| A1 广州开场 | 发「你好，想找工作」。等问城市后发「广州」，有多个岗位就选广州地铁安检。 | 顺序为岗位说明 → 工时待遇 → 工作视频 → 邀约。视频点开能播。记录各气泡收到的时间。 |
| A2 连发后插问 | 邀约后连续发「可以啊」和「可以只上一个班次吗？」两条。 | 先回答单班问题，保留候选人的顾虑，继续等明确面试意向。 |
| A3 还没决定 | 发「如果朋友那边没成，我明天上午再来」，等回复再发「好的」。 | 简短回应并等确认，期间没有正式面试通知、报名或群消息。 |
| A4 重新约及晚到 | 发「我确定要去面试」。收到安排后发「明天下午能晚一点到吗？」。 | 地址为冠宇商务中心，给当前岗位的可约时段并问几点能到。晚到提问后，预约状态仍待确认。 |
| B1 南昌开场 | 新会话发「我想找南昌的工作」，有多个岗位就选南昌地铁安检。 | 招聘介绍用南昌资料，试用期 80 元/班。已绑定食堂视频或宿舍图片时核对先后，最后收到邀约。 |
| B2 选时间并收资料 | 发「可以接受」，再分两次发有效日期和「下午三点」。然后快速分两条发测试姓名、手机号。 | 发财富大厦的面试安排。姓名和手机号都收齐后仅回显核对信息，面试登记此时为空。 |
| B3 确认、地图和群 | 发「确认报名」。等登记回复后再发一次同样的话。 | 第一次收到正式通知、可打开的高德地图和到达提示，有配置的路线图可以打开。面试登记只有一条，目标群只收到一条通知。 |
| B4 到场或取消 | 其中一个已报名测试会话发「我到了门口」，另一个发「我不去了」。 | 到场时按对应面试点给指引。取消表达后暂停排期提醒。用已配置提醒的账号验证，时间改动仍以面试登记实际值为准。 |

反馈时发用例号、城市、候选人的原话和收到的回复。顺序或延迟有问题时附连续气泡的录屏或时间，报名问题附面试登记和群回执状态。截图请遮住姓名和手机号。
