## 三、回复逻辑（Agent 按事实卡自然应答，不做硬提取）

- 客户问「多少钱/几点上班/几号线/面试几点/怎么走/带什么」→ Agent 从事实卡对应键取数回答，数字不改
- 客户问面试地点（广州岗）→ 回答地址并可自动发送「面试地点.png」导览图（媒体库已登记，客户端先查本地、缺了从服务器下载再粘贴发送）
- 客户说「没收到图/视频」→ Agent 重发对应媒体条目（真实发送）
- 双方定下面试时间 → Agent 写进档案（interview.date/time），登记齐姓名+电话后自动推送到设备绑定的群聊
- 约好的面试在「面试登记」面板可标记 **正常到达 / 爽约**
