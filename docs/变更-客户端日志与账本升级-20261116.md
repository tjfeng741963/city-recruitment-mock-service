# 变更：客户端日志与 reply_log 升级（2026-11-16）

> 范围：`agent/autopilot.py`、`agent/reply_store.py`、`agent/README.md`、`backend/tests/test_agent_logging.py`
> 不改：`agent/wecom_io_core/`、发送动作序列、4222/8090 接口
> 状态：本地已完成并跑测试，**未推送、未部署**

## 1. 改什么

### `agent/autopilot.py`

`log()` 从「`[HH:MM:SS] 纯文本`」升级为结构化单行：

```
[2026-11-16 23:54:52] [WARNING] [send] [知识库] 张三 ← '客户前20字' → '回复前200字…(486字)' message_id=S:1:123 trace_id=tr_ab12cd34ef56 duration_ms=5123
```

- 日期、级别、模块、关联字段；
- 级别/模块不传时按文案推断，现有 100+ 调用点不用改；
- 客户内容打码：手机号、身份证；
- 回复日志最多 200 字；
- `run.log` 20MB 轮转，保留 5 份；环境变量 `AGENT_LOG_MAX_BYTES` / `AGENT_LOG_BACKUPS` 可覆盖；
- 写日志异常继续吞掉，不影响业务。

发送路径补了 `message_id`、`trace_id`、`duration_ms`；人工指令补了 `command_id`；core 的步骤日志（`步骤0 前台就位` 等）也带上关联字段。

### `agent/reply_store.py`

`reply_log` 新增 4 列，老库启动时用 `PRAGMA table_info` + `ALTER TABLE` 平滑升级：

| 字段 | 说明 |
|---|---|
| `attempts` | 成功/失败/不明都 +1 |
| `trace_id` | 入站登记时生成，贯穿发送日志 |
| `last_step` | created/sent/failed/unknown/skipped/held/requeued |
| `duration_ms` | 成功发送耗时 |

`mark_sent` 新增可选 `duration_ms` 参数；原有 3 参数调用不受影响。

### 其他

- `agent/README.md`：补日志格式、轮转、字段与排查 SQL；
- `backend/tests/test_agent_logging.py`：3 个回归测试（格式/打码/轮转、账本迁移与 attempts）。

## 2. 为什么

现有日志只有 `HH:MM:SS`，没有日期、级别、模块、关联 id、轮转和脱敏；`reply_log` 是覆盖式状态，失败原因和尝试次数会被成功覆盖。排障只能 grep + 猜时间。

## 3. 影响

| 项 | 影响 |
|---|---|
| 日志格式 | 变了；按 `[HH:MM:SS]` 解析的临时脚本需要改 |
| grep | `[心跳]` 等旧前缀仍在正文里，旧关键字仍可搜 |
| 数据库 | 新增 4 列，自动迁移；不删不改旧字段 |
| 发送行为 | 不变 |
| `wecom_io_core` | 零改动 |
| 4222/8090 | 无接口变化 |

额外手工验证：

- 手机号 `13812345678` → `138****5678`；
- `LOG_MAX_BYTES=400` 时轮转出 `run.log.1..3`；
- 老 `reply_log` 表（无新列）启动后自动补列，`attempts` 从 0 开始；
- `mark_failed → mark_sent` 后 `attempts=2`、`last_step='sent'`、`duration_ms` 正确。

## 5. 回滚

```bash
git checkout -- agent/autopilot.py agent/reply_store.py
```

- 新列留在生产库不会影响旧代码（旧代码 `SELECT *` 会多出字段，但未使用）；
- 日志恢复旧格式；
- 测试文件可保留，不影响运行。

## 6. 风险

1. 日志正则解析脚本可能依赖旧时间格式；需要同步改。
2. `log()` 对整条消息做手机号/身份证打码，极端情况下会把正文里 18 位纯数字当作身份证打码；不影响发送，只影响日志可读性。
3. 轮转发生在写日志前；Windows 上如果另一个进程持有 `run.log`，`os.replace` 可能失败，此时继续追加，不会丢业务。
4. 新增字段让 `reply_log` 每行略大，可忽略。
