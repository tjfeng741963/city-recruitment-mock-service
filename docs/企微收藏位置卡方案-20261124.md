# 从企微收藏发送面试位置

2026-11-24 · 入口及按名称查找已确认，云 Windows 真机验收由用户执行

## 现状

截图里的企业微信支持在会话中从「文件 → 收藏」选择已有位置消息。系统已经识别客户发来的定位，岗位页也可以维护多个面试点。当前发送端支持文字、图片和视频。Dify 的面试导航已有高德地图搜索链接。代码里还没有从收藏选择并发送原生位置卡的链路。

收藏列表属于当前登录的企微账号。截图能证明这个账号有这些收藏，其他账号和另一台电脑上的实际可用项需要分别核对。

## 页面入口

唯一的配置位置放在「招聘资料 → 招聘岗位 → 编辑 → 面试与门店」。在每个面试点的地址下方关联「企微位置卡（选填）」。面试点已有的名称、地址、面试时间和到场指引继续作为招聘资料。一处面试点对应一张经确认的位置卡，同一个岗位有多个面试点时可以分别绑定。

```text
面试与门店
└─ 面试点
   ├─ 面试点名称、详细地址、面试时间、到场指引
   └─ 企微位置卡（选填）  收藏名称及地址 · 发送账号验证状态
```

在企微发送能力验证通过后再接入这个配置。运营只需填写收藏卡显示的名称，无需再抄一遍收藏里的地址。按名称搜索结果后，必须确认结果是位置卡且标题唯一匹配。定位以收藏卡本身为准，表单里手填的地址不作为匹配条件。若地图卡只到大楼，文字可补充已核实的楼层、房间及到场指引。网页的「话术流程 → 接待测试」复用已有测试入口，展示该轮采用哪个面试点和发送账号。对话管理用于核对会话中出现的实际消息。

## 发送规则

- Agent 和 Dify 共用岗位的面试点绑定。客户明确要定位或导航，且面试点已确定时，才尝试发送收藏卡。多点且含糊时先请客户选点。
- 仅使用当前接待账号已核验的收藏条目。名字填错、搜索无结果或出现多张同名位置卡时，不猜选。确有已核实的文字地址时沿用现有回复，Dify 继续提供现有地图链接。发现文字地址与已核实的收藏位置冲突时，先核对再发送文字地址。
- 一旦进入发送且结果不确定，标记「待核对」，避免盲目重发或重复补发。确认发送以后才显示「已发送」，需要在目标会话中读到匹配的新位置消息。对方收到由测试联系人确认。

## 验证与回滚

1. 选一个云 Windows 测试账号、一个收藏地点和一个测试联系人。先用企微原生界面手动发送，核对接收端能打开地图、地点与岗位资料一致，以及现有回读能否区分目标会话里的新位置消息。测试阶段不改正式招聘回复。
2. 如需新增桌面自动化动作，先根据实测记录当前发送路径缺哪一步、拟新增的动作、涉及的窗口、回读条件及回滚方式，再提交确认。冻结的 `agent/wecom_io_core/` 保持原样。收藏无法稳定定位或无法可靠回读时，保留现有发送方式。
3. 执行方式验证通过后，再分别测 Agent 和 Dify 的单点、多点、错账号、缺收藏和回执超时。分开记录配置保存、引擎选点、客户端发送和对方收到。
4. 自动发送通过验证且上线后，可按接待账号停用原生卡发送，恢复现有文字地址及各自已有的地图链接或地点图。

## 匹配程序与后续接入

1. Dify 或 Agent 确认候选人在问定位，并从当前岗位的面试点中确定唯一地点。系统由该面试点取保存的收藏名称。模型生成的地址、坐标或收藏名均不能作为发送依据。
2. Windows 核对当前企微登录账号与接待账号一致，用已有收藏选择框搜索该名称。匹配输入必须覆盖完整结果，并且能判断每条结果是不是位置卡。如果只读到当前可见的几行，或无法判断卡片类型，按「结果无法核对」处理。
3. `scripts/check-wecom-favorite-location.mjs` 负责匹配。仅忽略名称两端空白及 Unicode 标准等价差异，按完整标题匹配。文字收藏即使同名也不计入，两个位置卡即使显示地址一致也视为重名。唯一命中时返回该卡显示的标题和地址。地址只用于核对，地图点以企微原卡为准。
4. 真机通过后才接自动发送。客户端提交前再次核对账号、目标会话、面试点、唯一收藏结果。提交之后，以同一会话新出现、由本账号发出的真实位置类消息核对发送结果。若现有回读无法确认实际卡片是哪一张，测试时由收件人核对卡片标题和地图点。发生超时或结果不确定时停止该次操作，交给人工核对。

匹配程序通过标准输入接收 JSON，只处理调用方提供的结果。以下账号标识和结果均为演示数据，录入实际结果时账号应使用稳定 ID，例如设备绑定的企微账号 ID。`complete` 表示测试人员或后续客户端已经确认结果完整。

```powershell
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
@'
{
  "expected_account_id": "test-account",
  "favorite_title": "广汽本田龙华店",
  "snapshot": {
    "account_id": "test-account",
    "complete": true,
    "items": [
      { "kind": "other", "title": "广汽本田龙华店" },
      { "kind": "location", "title": "广汽本田龙华店", "address": "深圳市龙华区民治街道龙屋工业区7栋" }
    ]
  }
}
'@ | node scripts/check-wecom-favorite-location.mjs
```

`matched` 表示唯一命中，`not_found` 表示没有同名位置卡，`ambiguous` 表示同名位置卡超过一张，`account_mismatch` 表示当前账号不符，`incomplete_results` 表示搜索结果不完整，`invalid_input` 表示输入无法核对。`matched` 仅验证匹配规则，发送和对方收到各自单独核对。
