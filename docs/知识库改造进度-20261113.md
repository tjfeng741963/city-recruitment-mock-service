## 四、还没做的（按顺序）

### P1-1 把 FAQ 接进回复链路（**下一步就做这个**）

现状：`backend/app/api_flow.py:125` 调的是 `kb_placeholder.lookup_entry`（旧路径，扫 `kb_entry` 打分）。

要改成：

```
1. 先查 kb_faq（新路径，硬过滤 vertical + employer）
2. 命中 → 用 position.data_json + location 渲染占位符 → 直接回这句，保持原 stage
3. 未命中 → 回落到 kb_placeholder（旧路径，兼容已有 534 条话术）
4. 都没有 → unknown_questions + 兜底
```

**验证标准**：模拟客户问「包吃住吗」，在绑定 A 厂和绑定 B 厂的设备上分别得到 A、B 各自的答案，不串。
