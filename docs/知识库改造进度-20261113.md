## 四、进度更新：FAQ 已接入回复链路（P1-1 完成）

`backend/app/api_flow.py` 的插问分支改成两段式：

```
① 先查 kb_faq —— 按 vertical + employer 硬过滤，别家的条目不进候选集
② 命中 → 用岗位事实 + 面试点渲染占位符 → 直接回这句，保持原 stage
③ 未命中 → 回落 kb_placeholder（存量 534 条话术）
④ 都没有 → unknown_questions + 兜底话术
```

配套改动：

| 改动 | 文件 |
|---|---|
| config 接口透出 `vertical_id` / `employer_id` | `src/modules/messaging/device-bridge.routes.ts` |
| `_normalize_meta` 解析这两个字段 | `backend/app/services/device_scripts.py` |
| 占位符支持 `{name|兜底}` 语法 | `backend/app/services/kb_faq.py` |
| 4 条常空字段补兜底文案 | `src/db/migrations/023_kb_faq_fallbacks.sql` |
| 不串厂回归测试（11 例） | `backend/tests/test_kb_faq.py` |

### 4.1 模拟验证结果（真实岗位）

用客户资料里 **11 条真实工厂岗位** + **15 组截图问法** 跑通。三家厂对同一句话给出不同答案：

| 客户问 | 松下（GZ-PY-001） | 华荻（GZ-PY-004） | 华智（GZ-PY-005） |
|---|---|---|---|
| 包吃住吗 | 包吃包住，不扣水电 | 包吃，住宿补贴 200 元/月 | 包吃包住，宿舍水电平摊 |
| 要不要体检 | 不体检，直接入职 | 需要体检，体检费自理 | 统一体检，公司出钱 |
| 有花臂能进吗 | 松下发不查纹身，花臂也可以 | 华荻要查纹身，花臂进不去 | 华智查纹身，小图案可以 |
| 多少钱一个小时 | 这边工价是 19-23 元/小时 | 24-26 元/小时 | 24-26 元/小时 |
| 在哪个位置啊 | 面试地点在广东省广州市番禺区钟村 | …番禺区石楼 | …番禺区石楼 |

**「分不清厂」在数据层面已经解决**：同一句问法，绑定不同设备的客户拿到各自的答案。

### 4.2 调优过程中修掉的问题

| 问题 | 表现 | 修法 |
|---|---|---|
| 4 类问题整句消失 | 「买社保吗」「多久转正」「能借支吗」「太远了过来不方便」回复为空 | 占位符支持 `{name\|兜底}`，给不含数字的通用说法 |
| 地址为空 | 「在哪个位置」被整句丢弃 | 模拟脚本补上 `location_id`；真实链路里由设备 meta 带下来 |
| 全量跑时测试报 NOT NULL | SQLAlchemy `create_all` 建的表没有 DDL 默认值 | 测试自己 DROP 后按迁移语义重建 |
