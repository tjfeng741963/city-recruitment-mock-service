# 微信账号申请与分配云上 Agent

客户在「日常招聘 → 微信账号」的原账号行提交「联系管理员增加云上 Agent」。管理员在同一行打开「分配云电脑」，选择已登记、在线的空闲机器。运维操作只需选机器和确认。没有空闲机器时申请继续保留。

待申请 → 待管理员分配 → 正在配对 → Win 已连接 → 在原账号行扫码

机器预装由部署人员负责。空闲机器以自己的桥接身份通过可信 HTTPS 等待分配。服务端保留账号与机器的一对一分配记录，留存申请人与分配人。客户端保留原有配置备份，以试运行方式启用目标账号，并暂停自动发送。目标账号用本次凭据通过可信 HTTPS 上报有效的 Windows 运行状态，且企微进入扫码或确认登录后，分配才显示完成。账号名、岗位与话术继续使用原账号记录。机器掉线或启动失败时提示管理员核对，机器继续保留给同一账号。试运行期间若需要刷新二维码，由运维在云电脑的企微登录窗口操作。
