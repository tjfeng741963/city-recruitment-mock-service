# 面试登记与候选人同步

产品确认：AI 对话收集信息进入面试登记，候选人页以截图二列顺序展示同一份登记，并可查看对应真实对话。本轮获授权调整此前冻结的候选人页，对话管理原窗口不改。

- [x] 复现：候选名单丢失会话 ID/地区/姓名缺项，操作列固定为“-”；手动登记 INSERT 参数错位返回 500。
- [x] 同步：以 agent_archive 为唯一名单来源，按精确 external_conversation_id 关联会话；姓名、电话和面试时间优先使用档案；设备/地区/项目补充现有信息。
- [x] 页面：设备、昵称、姓名、电话、事件时间、面试日期、面试工厂、城市/区县、提醒状态、记录时间、对话记录；分页及 15 秒可见页刷新。
- [x] 对话：新增管理员只读记录接口，精确设备/客户 ID，支持向前翻页，不清未读、不生成消息；无关联会话不猜测。
- [x] 验证：档案更新、手动登记、已签到同步、精确对话及只读行为；Vue build、Node 全量、类型、API 与迁移检查，合并上线后只读核对真实名单。

历史缺失姓名/电话不由页面造数据。相同昵称不合并，相同手机不自动合并，避免把不同会话或招聘记录混成一个人。候选人页取消运行时补列，使用源码固定列避免重复及失效操作。

补充：多设备同 session_key 的历史记录标记会话待核对，返回 409 而不任意选择聊天。提醒状态按当前面试日期的 followup 任务及回执读取，修改面试日期后不沿用上次提醒结果。候选人筛选请求设序号保护，切换页签不会携带隐藏日期条件。
