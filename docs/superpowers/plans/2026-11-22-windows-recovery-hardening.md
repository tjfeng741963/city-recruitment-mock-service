# Windows 断线恢复加固

目标是恢复后完整补传 Win 仍可访问的企微消息，同时控制历史自动回复、准确显示三层就绪状态，并验证单实例恢复和备份。

1. 在 autopilot 使用只读消息快照的有序分页。游标和待上传项同一原子文件落盘，分账号和目标保存游标。复用服务端幂等键。恢复后过期入站单独标待核对，发送结果不明保留原记录。
2. 通过独立线程按固定周期报告 Windows、企微与业务执行状态。主循环没有进展时保持进程连通信息，并撤销回复就绪。网页利用现有客户端连接列展示各层和本地积压。只读生产巡检继续检查真实入库差异。
3. 登录启动入口监控同一进程。异常退出最多重试两次，使用现有互斥和交互桌面检查。人工停止写持久标记。备机只允许人工确认旧机已被隔离并恢复经过核验的业务文件。
4. 使用 SQLite 在线备份和隔离还原演练验证网页数据库、回复账本及工作流。同步游标与尚未上传的数据一起校验。验证 250 条积压、断线、重启、状态滞后和未知回执。

回退时保留恢复文件与原有队列，停回复后再安装上一正式版本。若恢复途中信号不明确，保留人工核对状态。
