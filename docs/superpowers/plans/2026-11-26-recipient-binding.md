# 同名会话核验

已确认的入口位于现有会话详情。仅当会话需要核对时，运营可以请求一条唯一企微备注，再从正确的企微会话手工填写。Win 用当前登录账号的数据源按会话成员回读备注，发送前再次核对界面标题。备注丢失或冲突时只暂停该会话。

实施步骤

1. 复用桥接配置与设备鉴权，记录绑定状态。网页提交代表备注已生成，Win 回读后才显示已确认。
2. 在回复账本保留因收件人无法确认而尚未发送的消息。绑定生效后只考虑最新、未尝试发送、有出站证据可核对且仍在时限内的文本。
3. 用回归测试覆盖同名、换备注、换账号、发送前界面变化和重复恢复。先在本地验证，再用同名测试会话做新 Win 实机验收。冻结的企微发送模块保持原样。
