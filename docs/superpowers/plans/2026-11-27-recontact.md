# 复聊板块实施计划

> 按任务逐项实现与核验。勾选项对应可运行的验证。

## 目标

让招聘者从独立的「复聊板块」配置超时复聊、确认老客户复聊，以及查看逐条发送结果。Agent 和 Dify 通过同一服务端队列下发文字、图片、视频及地图链接。

## 全局约束

- 依据[设计](../specs/2026-11-27-recontact-design.md)完成页面和真实执行链路。
- 复用 Fastify、SQLite、Vue、设备桥接与 Windows 现有发送模块。冻结的企微底层文件和键鼠动作序列沿用原实现。
- 自动规则默认停用。新协议仅下发给声明支持的客户端。按回执区分已发送、失败及待核对。

- [x] 增加 069 迁移和 `src/modules/recontact/`，持久化岗位规则、模板、预览、任务、发送步骤及触发证据。按岗位和账号权限提供管理 API。
- [x] 把 Agent 和 Dify 实际回复回执接入自动任务，按北京时间发送时段和客户端回执推进步骤。用共享会话归属阻断重复触发。

## 任务二：企微客户端
