# 对话模拟测试记录（2026-11-11 凌晨）

> 方法：模拟真实用户对线上 8090 跑 7 个场景，逐轮记录，抓出问题 → 修复 → 复测。
> 覆盖：正常全流程、首句插问、城市不匹配、换岗位、砍价、只给姓名、收集后插问。

---

## 一、实测发现的问题（按严重度）

### 🔴 1. 城市话术串台（最严重）
```
客户：东莞
AI：长安五金厂在招长安五金厂 操作工…   ← 这段是「广州」的设备话术模板！
```
根因：`pick_script` 匹配失败时有个末级兜底 `candidates[0]`——**城市对不上也命中**。
广州配的话术被发给了东莞客户。
**修复**：城市非空时必须精确匹配或话术 city 为空（通配），否则不命中。

### 🔴 2. 脏岗位直发客户
```
客户：深圳
AI：示例电子厂在招示例产线岗位：，，，。地点示例电子厂…   ← 字段全空的种子数据
```
根因：深圳在 4222 只有一条全空示例岗位，且没有过滤。
**修复**：工价/班次/吃住全空的岗位剔除；剔除后没有可用的 → 回落到演示数据（保证话术永远完整）。

### 🟡 3. 「还有别的厂」被当未知问题吞掉
```
客户：有没有别的厂，这个太远了
AI：这个我确认一下，稍后回你          ← 客户明明在要岗位列表
```
根因：换岗位意图没有实现，走到了知识库兜底；而且模型不知道岗位列表，让它答必然编造。
**修复**：`send_info / ask_interview` 阶段命中意图词（别的/其他/换一个/还有/哪些厂…）→
由**代码**列出该城市其他岗位（排除已发过的），不过模型。

### 🟡 4. 知识库话术内容质量
砍价场景命中了一条 KB 话术，内容是对的但格式乱（强制换行）、且有「国企编制」这类
与蓝领岗位不符的表述被匹配到。**这是录入质量问题不是代码问题**——话术库正式启用前需要整理。

### 🟢 5. done 后完全静默（维持设计）
约完面试后客户问「宿舍几人间」→ 不回复。客户方明确要求"约成就没有后续"，
维持设计；若后续要改成"答一句但不推进"，改 done 分支一处即可。

## 二、修复后复测结果

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 深圳（只有脏岗位） | `示例电子厂：，，，。` | 回落演示数据：龙华电子厂（质检）20 元/小时，字段齐全 |
| 东莞（串城话术） | 广州话术模板 + 厂名复读 | 标准三段：厂名/工价/地点时间/邀约 |
| 有没有别的厂 | 「这个我确认一下」 | 列出该城市其他岗位（宝安玩具厂、龙岗物流园…）+「想看哪个跟我说」 |
| 还有什么岗位 | KB 乱命中（国企编制） | 正确列出虎门电子厂、厚街鞋厂 |
| 正常全流程 | ✅ 本来就通 | ✅ 不受影响 |

## 三、流程逻辑的结论（当前设计）

**"前段代码、后段模型"的分工是对的，而且比想象的更细：**

| 阶段 | 谁负责 | 原因 |
|---|---|---|
| 问城市 | 模型 | 客户说法千奇百怪（"我在番禺"），但要抽的只是一个城市字段 |
| 发岗位信息 | **纯代码** | 工价/年龄一个字都不能错，模型复述=把事故交给运气 |
| 问面试 | 模型 | 客户表态方式太多样（"可以"/"再看看"/"明天下午行吗"） |
| 插问（体检/住宿/地点） | **纯代码**（知识库命中原话） | 模型自由发挥最容易编出「体检费厂里全报」这种要赔钱的话 |
| 收姓名手机 | 模型抽取 + 代码校验 | 缺一个只追问缺的那个 |
| 换岗位 | **纯代码**（新增） | 岗位列表模型看不见，让它答必然编造 |
| 约成/拒绝后 | 静默（纯代码） | 防止模型把状态改回去 |

规律：**涉及数字和事实的输出全部锁死在代码里；模型只负责理解意图和组织自然语言。**

## 四、遗留观察项（不算 bug，但要盯着）

1. 砍价/合规类插问依赖 KB 话术质量——话术库内容整理是上线前必须做的
2. `looks_like_question` 的判定边界：客户在 collect 阶段说方言式回答（"中""得行"）目前走模型，正常
3. done 后完全静默在"客户到了找谁"场景显得冷硬，客户方已确认接受
4. 设备话术配了但没写邀约问句时，流程会停在 ask_interview 等客户开口——运营配话术模板需自带邀约句（页面 placeholder 已提示）
