# 设备自注册（方案 A）

> 目的：把「管理员手工建码 → 拷进 config.json」换成「客户端首次启动自动注册」。
> 适用范围：单租户自用。给第三方公司用之前必须先做多租户隔离（见文末）。

## 一、流程

```
客户端首次启动
   │  config.json 里 device_token / bridge_token 任缺，且填了 register_key
   ├─→ 算机器码  pc-<sha256(MachineGuid) 前 12 位>
   ├─→ POST 8090  /api/v1/devices/register                X-Register-Key: <key>
   │        └─ 返回 device_token
   ├─→ POST 4222  /api/v1/bridge/devices/<code>/register   X-Register-Key: <key>
   │        └─ 返回 bridge_token
   └─→ 写回 config.json（新机器自动 dry_run=true）
```

同一个 `device_code` 重复注册**不新建记录**，只换发 token（旧 token 立即失效）。
设备被管理员停用后，客户端无法靠重复注册把自己激活回来。

## 二、配置

### 服务端

| 服务 | 变量 | 说明 |
|---|---|---|
| Node 4222 | `REA_REGISTER_KEY` | 空 = 关闭（返回 503）。少于 16 字符也按未配置处理 |
| Python 8090 | `APP_REGISTER_KEY` | 同上 |

两边用**同一个值**，客户端只填一次。

生成示例：

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### 客户端 `agent/config.json`

```json
{
  "server": "http://119.91.113.100:8090",
  "register_key": "<与服务端一致>",
  "device_code": "",
  "device_name": "办公室-台式",
  "dry_run": true
}
```

- `device_code` 留空 → 自动生成 `pc-xxxxxxxxxxxx`
- `device_name` 留空 → 用 `device_code`
- `dry_run` 新机器默认 `true`：先只看不发，确认无误后再改 `false`

## 三、手动验证

```bash
KEY=<服务端配置的密钥>

# 8090：换 device_token
curl -s -X POST http://119.91.113.100:8090/api/v1/devices/register \
  -H "Content-Type: application/json" -H "X-Register-Key: $KEY" \
  -d '{"device_code":"pc-manualtest","name":"手动验证"}'

# 4222：换 bridge_token
curl -s -X POST http://119.91.113.100:4222/api/v1/bridge/devices/pc-manualtest/register \
  -H "Content-Type: application/json" -H "X-Register-Key: $KEY" -d '{"name":"手动验证"}'
```

预期：8090 返回 `201 + device_token`；4222 返回 `201 + device_token`（64 位十六进制）。
第二次调用返回 `200`，token 变、不新增记录。

## 四、安全边界

- 这是**唯一**一条无需登录就能写库的路径。密钥未配置时整个入口 503，不会默认放开。
- 注册出来的设备固定带 `observe_only: true`：Node 侧只记录不自动回复，避免和 Python 知识库重复回复。
- 密钥泄露 = 任何人都能往设备表里塞记录。发现泄露就换 `REA_REGISTER_KEY` / `APP_REGISTER_KEY` 并重启两端；已注册的设备记录需要人工清理。

## 五、尚未支持

- **多租户**：`tenant_id` 只在表结构里，Node 侧 0 处按租户过滤，Python 侧 74 处全是硬编码 `DEFAULT_TENANT_ID`。接第二个客户前必须补齐，否则数据互通。
- **商用授权**：`agent/DISCLAIMER.md` 禁止商业使用与多租户托管，需版权人书面授权。
