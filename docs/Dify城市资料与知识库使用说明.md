# 模式二：从原城市资料与知识库配置招聘回答

1. 在「招聘资料 → 城市与项目」编辑城市。原有工资、工时、面试时间/地点、联系人、通知模板和指引均已显示。
2. 点「编辑完整城市原文资料」可维护吃住、工作内容、环境、行李、报名表单、补充说明以及旧版本自定义段落。工资等重复内容统一在上方输入框编辑，保存同步历史别名。
   「模式二知识品类」选择地铁安检/工厂等，复用该品类已有且通过校验的问答模板；留空只用无品类通用和本岗位问答。修改地址后须同时核对面试指引与岗位知识里写死的地点。
3. 在「AI 接待 → 话术流程」选择岗位，再打开「岗位配置 → 岗位问答」，维护已启用的通用/该岗位问答。模式二每轮读取所属城市，城市空白项才沿用当前岗位；不会读取其他岗位知识。
4. 在同一知识库页面的「模式二 · Dify」区域输入问题，先查看回答依据，再生成模拟回答。这里只试答，不发送企微或改变设备模式。
5. 首页原有 Dify失败、AI异常和排队堆积读取真实调用/命令记录。模式一与模式二仍按设备独立选择。

城市长原文和大量知识按问题相关性选完整条目，依据里显示本轮入选知识及省略数量。关键工资/时间/地点不截断；过长时暂停并提示精简。若资料在生成期间修改，旧回复暂停。

明确的面试地址/指引目的楼层冲突会暂停生成并提示核对。该检查不替代人工核对全部原文；工作地点与面试地点是独立事实。模式二目前支持文本岗位咨询与面试意向，不包含自动OA登记、群通知或自动发送图片视频。
