# 模式二：从原城市资料与知识库配置招聘回答

1. 在「招聘资料 → 城市」维护名称、省份和区县。从「查看岗位」进入该城市的招聘岗位。
2. 在「招聘岗位 → 编辑岗位」维护工资、班次和面试安排。在「问答知识库」维护通用及岗位问答。
3. 在「话术流程 → 接待测试」选择岗位和回复引擎，核对回答依据和模拟回复。实际回复引擎在「微信账号」按设备选择。
4. 历史城市默认资料保留在原记录中。Dify 仍优先采用适用的历史城市字段，城市空白项再沿用岗位资料。可在岗位表单查看城市工资和班次，在接待测试中查看完整输入来源。

城市长原文和大量知识按问题相关性选完整条目，依据里显示本轮入选知识及省略数量。关键工资/时间/地点不截断；过长时暂停并提示精简。若资料在生成期间修改，旧回复暂停。

明确的面试地址/指引目的楼层冲突会暂停生成并提示核对。该检查不替代人工核对全部原文；工作地点与面试地点是独立事实。模式二目前支持文本岗位咨询与面试意向，不包含自动OA登记、群通知或自动发送图片视频。
