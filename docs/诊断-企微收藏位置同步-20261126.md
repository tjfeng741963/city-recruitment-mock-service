# 企微收藏位置同步实施记录（2026-11-26）

## 诊断

云 Windows 的企业微信「文件 → 收藏」可以看到真实位置收藏（冠宇商务中心、百花广场、广汽本田龙华店等）。现有服务端只接受单张 `WeWork Message` 原始字节上报，且位置卡只按全局 sha 保存；客户端没有收藏快照、账号归属、完整性状态或删除同步。因此岗位下拉框无法可靠列出当前接待账号的收藏。

## 本次范围

- 增加账号/设备作用域的收藏快照表，保存收藏标识、标题、地址、卡片 sha 和完整性状态。
- 增加设备上报收藏快照接口，拒绝账号不一致，完整快照才执行删除 reconciliation。
- 位置卡列表按设备账号过滤，返回可绑定的原始卡元数据。
- 在现有「招聘岗位 → 编辑 → 面试与门店 → 面试点」中提供收藏下拉选择，保存 `location_card_sha` 和标题。
- 保留旧的地址/导航链接行为；没有真实收藏快照时不伪造为已同步。

客户端采集器已接入已有桥接心跳：每 5 分钟只读扫描账号 `kv.db`，完整读取才上报 `complete=true`；能识别原始 `WeWork Message` 字节时先上报位置卡，再提交收藏快照。扫描失败或 schema 无法确认时上报不完整状态，不清理服务端旧收藏。本次不新增企微点击或发送动作。
